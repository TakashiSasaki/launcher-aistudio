Overview

段階的に変更した三つのモデル

この会話では、最初の平面グリッドから、周期境界を持つトーラス、さらにマンハッタン距離と可変指数を用いるモデルへ段階的に拡張しました。

1

平面グリッド

通常の矩形グリッドとユークリッド距離二乗を使用します。基本的な交互割当と画面切替を確認する基準モデルです。

2

トーラスグリッド

左右端と上下端を接合し、周期境界をまたぐ最短距離を使用します。表示は周期複製をスクロールします。

3

マンハッタン距離

上下左右のマス数を距離とし、コスト dMp の指数 p を1.0から2.0まで変更して比較します。

Interactive demonstrations

対話型デモ

各ページはHTML、CSS、JavaScriptを単一ファイルに収めています。乱数シード、平均次数、反復回数などを変更し、同じグラフに対する配置の差を比較できます。
